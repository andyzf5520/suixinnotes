# 随心记事本 iOS · v1.0.0 · 作者 andy

SwiftUI / iOS 16+。XcodeGen 根据 project.yml 生成 Xcode 工程；应用显示名称“随心记事本”，内部 target 名 ShijianNotes 保留。

已实现源码：笔记与账号、分类与独立加密、搜索排序、列表/卡片、深色模式、图片、顶部格式、撤销重做、自动保存、显式返回保存、HTML/TXT/CSV、完整加密备份及恢复。

平台差异：iOS 没有 Android 公共 Download/Notes，导出使用系统文件位置选择器；系统不允许应用统一禁止用户截图，切换后台用遮罩并保存后锁定。编辑页禁止直接下滑关闭，使用返回/完成按钮以保证保存；恢复为校验后确认切换，私密分类仍需各自密码。当前没有 Android 全部个性化选项、分类重命名、改主密码和回退版本切换 UI。

源码通过 GitHub macOS CI 构建与测试后才能称为编译验证版；iOS 模拟器 zip 仅用于 Mac 模拟器，不能直接安装到 iPhone。真机需要个人 Apple 开发团队签名；本次不上传签名证书、密钥或账号。

密码与私密内容只在会话内解密；历史不序列化。后台写入受系统时间和文件保护限制，不能保证磁盘失败后未提交内容恢复。请先使用虚构数据测试。
