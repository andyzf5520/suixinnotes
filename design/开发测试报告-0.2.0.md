# 开发测试报告 · Android 0.2.0

2026-10-02 · 开发验证版

## 本轮需求与结果
| 用户要求 | 已实现 |
|---|---|
| 排序 | 修改时间最新/最早、标题升序/降序；置顶优先；偏好持久保存 |
| 一行一个或卡片 | 首页可直接切换单行标题列表/双列卡片；两者不展示正文、用户名、图片摘要和时间 |
| 内容优先 | 编辑器正文为主要区域；字体、字号、默认样式为顶部下拉框；插图为小图标；底色、置顶等收进更多菜单 |
| 无标题取首行 | 列表、卡片、排序和导出共用显示标题规则；空首行用“无标题”，不读取密码字段 |
| 我的改设置 | 底部显示设置，包含分类、个性化、备份导出和主密码管理 |
| 导出备份默认位置 | Download/Notes；Android 10+ MediaStore，Android 8/9 旧版存储授权；可切换每次另选位置 |

HTML/TXT/CSV 导出、密码默认遮罩与确认、加密完整备份及恢复继续保留。文件名带时间戳，避免覆写已有文件。默认目录写入失败不显示成功；MediaStore 文件先 pending 写入再发布，失败清理新记录。

## 尚未验证
adb devices 未发现连接手机。本工作区没有配置模拟器。未执行真实 MediaStore 写入、Android 8/9 权限同意与拒绝、文件选择器、键盘遮挡、系统大字体、编辑器布局、后台锁屏和手机备份恢复流程。浏览器工具禁止访问 file: 页面，因此本轮原型只完成源文件静态检查，没有完成浏览器视觉验收，也未通过其他方式绕过访问限制。

DownloadsWriter 是 Android 平台代码，JVM 测试不替代系统目录写入验收。会话保存故障测试使用内存替身，不替代真实断电、磁盘满与 AtomicFile 测试。

## 仍有的范围限制
整库最多 48MB；每条最多 6 张缩图，图片转 JPEG，EXIF 方向纠正尚未实现。样式仍作用于整篇正文。自动备份、回收站、选区富文本、贴纸、模板包、跨分类移动、分类密码修改、指纹解锁、同步和 iOS 尚未实现。密码遗忘没有恢复服务。保存失败后锁定或结束进程不保证尚未提交的内容恢复。当前为调试签名开发版，正式发布与独立安全审核尚未完成。
