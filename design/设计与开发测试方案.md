# 墨匣：手机安全笔记 App 设计与开发测试方案

版本 v0.3 · 2026-10-02 · 仅手机端 · Android 首版

## 1. 产品方向
采用类似小米笔记的轻量体验：打开就是卡片笔记，快速记录、全屏编辑、分类筛选、待办和私密空间。在此基础上增加结构化账号密码、独立加密分类、图片、笔记外观自定义及可靠导出备份。首版使用 Android 原生界面，最低 Android 8.0；iOS 若需要另排阶段。离线、无需注册，不提供网络同步。

用户已授权设计完成后直接开发测试。本文件既记录目标，也区分首轮实现与后续功能，避免把原型当成已交付 App。

## 2. 参考与取舍
- 小米官方笔记说明中的私密笔记入口与密码访问：https://www.mi.com/uk/support/article/KA-07842/ 。借鉴手机笔记体验，不复制商标、素材或内部实现，不宣称与当前某个版本完全一致。
- KeePass 的账号字段与加密分组：https://keepass.info/features.html 。
- Joplin 的笔记与附件：https://joplinapp.org/help/apps/attachments/ 。同步加密不等于本地加密，墨匣首版明确加密本地文件。

首页不是账号后台。账号卡片是笔记的一种类型；私密保护不会被主题与布局设置改变。

## 3. 功能及交付阶段
| 模块 | 首轮开发范围 | 后续增强 |
|---|---|---|
| 笔记 | 新建/编辑/删除、自动保存、搜索、置顶 | 回收站、历史版本、标签 |
| 账号密码 | 标题、用户名、密码、网址、说明；密码遮罩/复制/随机生成 | 自定义字段、TOTP、系统自动填充 |
| 分类 | 自定义名称、颜色、新建、重命名、筛选 | 图标、自定义排序、嵌套、跨分类移动 |
| 加密分类 | 创建时设独立密码，显式解锁/重新锁定；主密码不能替代 | 更改分类密码、已有分类保护域转换、恢复密钥 |
| 图片 | 系统选择器插入、查看、移除；加密保存 | 拍照、剪裁、标注、OCR、保留原图导出 |
| 笔记样式 | 整篇字号/默认/衬线/等宽字体、粗体、斜体、卡片底色 | 选区富文本、正文颜色、高亮、表格、手绘、贴纸 |
| 个性化 | 深浅主题、主题色、双列/列表、默认字号 | 自定义字体包、主题包、布局预设、自建模板、桌面小组件 |
| 备份恢复 | 手动完整加密备份、口令验证、恢复预览、恢复前本地回退版本 | 自动定时、保留策略、多份版本管理、端到端同步 |
| 导出 | HTML 含图片、TXT 纯文本、账号 CSV；范围确认、密码默认排除 | 长图、PDF、Markdown、通用文件导入 |
| 安全 | 主密码、改主密码、分类独立密码、切后台锁定、空闲锁定、截图保护 | 指纹/面部快捷解锁、按分类自定义超时 |

导出及备份属于核心功能，两者不同：导出用于查看/迁移，有明文风险；加密备份用于完整恢复。

## 4. 手机交互与原型
prototype.html 展示手机首页、账号卡片、笔记编辑、分类、私密访问、个性化与备份。所有原型数据虚构；原型交互不做真实加密或文件保存。

- 底部导航：笔记、待办、设置。首页顶部搜索、分类标签、排序及列表/卡片切换，右下角新建。
- 新建底部/弹窗选择：空白笔记、账号卡片、待办清单。若当前分类已锁定，先解锁再创建。
- 编辑：全屏正文，账号页另有专用字段；字体、字号和样式通过顶部紧凑下拉框选择，插图是顶部小图标，置顶/待办/底色/删除放在更多菜单，返回前提交保存。编辑 1.2 秒无变更后提交自动保存，状态显示“正在保存/已加密保存/错误”。
- 私密分类：名称默认可见；锁定时隐藏条目标题、正文、账号字段、图片与数量，搜索不包含其内容。首版不隐藏分类名，用户可起通用名字。
- 备份：默认保存到 Download/Notes→输出完整加密文件，允许改为每次另选位置。恢复：选文件→主密码→校验预览→明确确认→切换；恢复前当前库保留一个加密回退版本。
- 导出：范围为全部已解锁分类或首页所选分类，列出未包含的锁定分类；选格式→确认；若包含密码再输入主密码。CSV 只包含账号，TXT 不包含图片与样式，HTML 包含图片与基础格式。

视觉：柔和纸张卡片、圆角、留白、暖棕默认主题，另有紫/绿/粉色；尽量单手操作，触控区至少 48dp；支持系统字体缩放。原型和 App 保持相同的信息架构，Android 系统控件外观可能不同。

## 5. 加密与访问设计（首轮实际方案）
- 主库：AES-256-GCM 认证加密 JSON 数据，随机 16 字节盐、12 字节 nonce。PBKDF2-HMAC-SHA256 600,000 轮派生密钥，依赖 JCA 标准实现，不自创加密算法。参数与格式版本写入认证头；导入限制 KDF 参数，阻止无限计算。
- 分类：独立密码直接保护该分类的密文内容；主库中仅保存分类壳与该密文。内层认证数据绑定分类 ID，避免错配。账号字段、正文、样式及图片均放在对应保护域。锁定删除分类会话内容，搜索仅读取已解锁集合。
- 主密码修改重加密当前主库，不修改分类密码；旧备份仍使用旧主密码。完整备份复制主库密文，包含未解锁分类；主密码不是独立分类的恢复凭据。
- 首轮不采用先前桌面草案中的 Argon2id + 包装数据密钥；该方案可作为未来性能与安全升级候选，必须增加格式迁移和兼容测试。
- 数据只保存在应用私有目录的密文文件；写入使用 AtomicFile，失败时保留已提交版本。没有明文数据库、索引或图片缓存文件。搜索在内存进行。
- 无注册、无找回服务。遗忘主密码或分类密码将无法访问相应内容；备份只防止数据丢失。

安全边界：保护锁定后的文件被拷贝、分类未授权读取及密文篡改；不能保护已解锁时被入侵的系统、外部拍照、恶意输入法或用户主动明文导出。托管字符串无法承诺彻底清除内存。

会话：切后台默认锁定并释放会话；系统文件/图片选择器有最长 2 分钟操作宽限；屏幕关闭立即锁定；无操作 5 分钟锁定。启用 FLAG_SECURE 防止普通截图和任务缩略图泄露，具体效果须真机验证。密码剪贴板标记敏感，30 秒后仅在仍是原内容时尝试清除；后台限制可能影响时效。

系统自动备份及设备转移通过清单与 XML 规则排除应用数据。用户备份走本应用的加密归档。参考 Android 官方：https://developer.android.com/identity/data/autobackup ，https://developer.android.com/develop/ui/views/touch-and-input/copy-paste 。

## 6. 数据、容量与导出格式
实体：Vault（分类、普通记录、偏好）、Category（名称/色彩/密文）、Note（类型、字段、正文、图片、样式）、临时分类会话。分类密文内容不出现在外层普通记录数组。

首轮为整库加密文件，限制 48MB、最多 100 个分类、普通记录最多 10,000 条；每条最多 6 张图片。输入图像 ≤20MB/4000 万像素，导入时缩至约 1600px、转 JPEG，单图输出 ≤2MB，去除原始元数据。此方案适合验证功能链路，不能宣称支持大规模原图资料库；大量图片时下一阶段改为流式加密附件存储。

.mxbak：版本化加密完整归档，备份时的主密码解密；分类仍使用对应分类密码。恢复前验证格式、大小、认证和分类引用。预览仅展示普通记录数量与私密分类数量，不为了统计强行解锁私密分类。连续恢复只保留一个本地回退版本；重要数据需外部备份。

HTML：转义标题、正文、网址，图片使用内嵌数据；不插入远程图片与脚本。TXT：明确提示图片丢失。CSV：转义引号与换行，防止公式注入，仅包含账号条目。密码默认隐藏，包含时需重新验证主密码。导出文件不是加密备份。

## 7. 技术与开发流程
Kotlin + Jetpack Compose 原生 Android，Android 8.0 起；Java 17、AGP 8.7.3、Kotlin 2.0.21、已验证环境中的 Compose 依赖版本。无网络权限，图片和文件通过系统选择器，不申请全盘读取。实现分为 Crypto、Models/Exports、VaultStore/Session、Compose 界面。

流程：需求与手机原型→最小纵向链路→密码与分类隔离→账号/笔记/图片→个性化→备份恢复/导出→单元与静态检查→真机流程验证→APK 交付。

每次新增安全或存储行为，应测试错误口令、密文篡改、读写失败、生命周期中断及恢复。编译、单元测试、Android Lint 全部通过后才作为开发验证版交付。首轮 APK 不等同于最终安全审计和正式发布。

正式版本预计需 8–10 周单人开发与适配，取决于增强功能范围；本次先交付核心功能开发版，不把时间估算当承诺。

## 8. 测试与验收清单
| 场景 | 标准 | 证据方式 |

发布门槛：核心流程通过、无严重数据丢失与泄露问题、外部备份在全新环境恢复成功、加密文件和临时目录明文扫描、升级/签名与许可证审核完成。重要真实凭据使用前仍需真机与独立安全评审。

## 9. 2026-10-02 交互修订（App 0.2.0）
- 首页支持双列卡片或一行一条的标题列表；两种形式都不展示正文、用户名、图片摘要或时间。单行超长标题省略。
- 排序：修改时间最新/最早在前、标题升序/降序；置顶始终优先。排序与布局保存在加密偏好中。
- 显示标题：优先手动标题；留空时取正文第一行（去首尾空白、最长 300 字），第一行为空则“无标题”。不会从密码或用户名推导，也不强制写回手动标题字段；导出沿用同一规则。
- 编辑页以正文为主，移除底部大型格式与插图面板。顶部提供默认字体、字号和默认样式下拉选择及小插图图标，更多菜单收纳置顶、待办、卡片底色、删除。
- 底部“我的”更名“设置”，包含分类、个性化、导出备份与密码管理。
- 导出和加密备份默认写入 Download/Notes，使用带时间戳文件名避免覆盖。Android 10+ 用 MediaStore.Downloads，无存储授权；Android 8/9 按需请求旧版存储权限，拒绝则进入系统另存对话框。设置可关闭默认目录，选择每次指定位置。
- 默认目录写入失败不显示成功；Android 10+ 先 pending 写入再发布，失败清理创建的记录。实际文件写入和系统授权仍待真机测试。

## 10. App 0.3.0：撤销重做与返回保存
编辑顶栏提供撤销/重做图标，空历史时禁用；保存不清空当前会话历史。文本、标题、格式和图片修改纳入最多 100 步会话历史。撤销后新增编辑清空重做分支。历史不落盘、不导出，退出编辑、删除、恢复或锁定清除。
系统返回键/返回手势及顶部返回都提交最新草稿后退出；自动保存正在进行时保留退出请求，完成后检查是否有更新，再提交最新草稿。写入失败取消退出，留在编辑器显示错误。输入法可先消费返回操作收起键盘，真正离开编辑页时才执行保存。


## v1.0.0 最终交互修订（2026-10-02）

应用名称：随心记事本；作者 andy；公开仓库 andyzf5520/suixinnotes。版本和仓库集中在设置 → 关于。

手机左侧为可收起的分类导航与分类内的单行标题索引，分类支持置顶；右侧顶部为搜索，主屏默认一行一个便签，标题下显示修改日期和分类图标。支持卡片样式切换、时间/标题排序。编辑器打开后使用主要屏幕空间，顶部小菜单控制字体/字号/样式，图片使用小图标；无标题采用正文首行。

普通笔记自动进入，本地库随机访问凭据由 Keystore/Keychain 保护，私密密码不持久保存；旧版本地库首次迁移需原密码。内置“私密”只在访问时需密码，设置里首次添加、后续修改。右侧可以单选/多选移入其他分类，涉及加密目标先验证密码。移动使用单次持久化事务；失败时保留原库和记录。

备份单独设置至少 8 位密码，备份包含所有未解锁分类的内层密文；恢复使用备份密码，私密仍需备份时的密码。Android 导出默认 Download/Notes，iOS 系统选择位置。

开发验收流程：实现并编译 → 加密/移动/备份/历史核心测试 → Android Lint → Android/iOS 模拟器界面流程 → 核对版本及打包哈希 → 推送源码与 v1.0.0 标签 → GitHub Release 资产校验。无法以模拟器结果代替所有真机验收；iPhone 签名交付需 Apple 团队证书。
