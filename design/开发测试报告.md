# 随心记事本 v1.0.0 开发测试报告

测试日期：2026-10-02（Asia/Shanghai） · 作者 andy

## 已实现的最终需求

普通笔记自动进入；左侧逐行分类及标题索引、分类置顶；右侧默认逐行便签，标题下显示日期与分类图标，支持卡片切换和排序。右侧单选或多选可移入其他目录；加密目标须先验证密码。设置中首次创建及修改“私密”密码；设置 → 关于展示版本、作者和 GitHub 链接。

文本、账号密码、待办、图片、自定义分类；顶部字体/字号/样式菜单及插图图标；撤销/重做；返回保存。HTML/TXT/CSV 导出、独立备份密码的加密备份与恢复。Android 默认保存位置 Download/Notes。

## 核心和构建检查

本地 Android assembleDebug、assembleDebugAndroidTest、testDebugUnitTest、lintDebug 通过。39 项 JVM 测试，0 失败、0 错误；Lint 报告 No issues found。

- CoreTest：15 项，加密错误密码/篡改、备份格式、图片模型、导出转义及两端共享 UTF-8 密码夹具。
- DisplayTest：6 项，标题回退、排序及偏好。
- EditHistoryTest：6 项，撤销、重做、新分支及容量限制。
- SessionTest：12 项，独立私密内容隔离、加密/普通混合批量移入、移回普通分类、密码更新、独立备份密码、分类置顶；模拟磁盘满时原文件和内存记录保持不变。

原型 JavaScript 语法检查、DOM ID 唯一性与引用检查通过；浏览器对本地文件访问受限，未将静态检查冒充视觉验收。

## 验收边界

模拟器验证不等于所有真机型号验收；当前没有连接 Android/iPhone 真机。照片选择器、Android 8/9 存储授权拒绝、系统文件选择器取消、实际后台进程被杀及输入法返回消费等仍需真机体验。没有独立安全审计。

Android 交付为调试签名 APK；iOS 交付为源码及 Mac 上的 iOS 模拟器应用 ZIP，不能安装到 iPhone。真机 IPA 需要 Apple 签名。Android 8.0+；iOS 16.0+。iOS 使用文件选择器，不能强制公共 Download/Notes 路径。

证据：design/test-evidence 的 JVM XML、Lint 文本和最终 CI 记录。发布包和 SHA256SUMS 位于 release/v1.0.0，作为 GitHub Release 资产，不写入 Git 源码。
